# 门店操作手册 · 企业微信录音日报

管理员完成一次配置后，栖鉴按北京时间每天 09:00 给内部门店管理群发送昨日的挂牌和胸牌录音分析。店长能直接在群内查看重要事件、逐员工话术与待解决事项。

## 1. 准备企业微信内部群

1. 在电脑打开[企业微信官网](https://work.weixin.qq.com/)，下载桌面客户端并登录。门店已有企业时，请管理员邀请你加入该企业。首次开通由负责人创建企业，并邀请需要接收日报的管理人员。
2. 在电脑端切换到酒店所属企业。使用已有的内部管理群，或发起群聊，把需要看逐员工报告的管理人员加入群。先核对群成员。
3. 右键目标群，选择「管理聊天信息」，点「消息推送 → 自定义消息推送」。某些版本显示「添加群机器人」，或者直接打开创建窗口。
4. 填写名称“栖鉴录音日报”，按界面提示填写简介和头像，复制 **Webhook 地址**，保存。地址通常以 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=` 开头，连同后面的密钥一起复制。请直接粘贴到栖鉴配置页。
5. 如果找不到入口，请群主或企业管理员在桌面客户端核对内部群类型和机器人权限。已创建的地址由创建者查看。腾讯提供逐步界面截图。[腾讯官方操作指引](https://cloud.tencent.com/document/product/1759/128391)

## 2. 在栖鉴验证目标群

1. 在门店主机打开 [栖鉴工作台](http://127.0.0.1:8765)，点左侧「挂牌与胸牌语音」，进入顶部「企微连接」。
2. 用管理员账号将地址粘贴到「群 Webhook」。首次配置时先保持自动发送关闭，点击「保存推送设置」。再次打开只显示配置状态，地址输入框留空即可沿用。
3. 点「发送测试消息」，在目标群确认收到 **栖鉴连接测试**。按钮返回成功代表企微已接收请求，群成员可以核对群名和实际显示的消息。
4. 如发错群，保持自动发送关闭，用正确群新建的地址覆盖保存，再测试。更换地址将取消尚未完成的投递。如密钥泄露，在企微群中移除旧推送，重新创建并保存新地址。

## 3. 登记员工与门店话术

1. 在「设备」点目标设备，填写「固定佩戴员工 → 员工姓名、绑定生效日期」，点「保存员工绑定」。使用每位员工一致、可区分的姓名或门店工号。设备换人时新增生效日期；解除绑定时将姓名留空并保存。生效时间为所选日期北京时间零点，同一日期重新保存会替换该日绑定。
2. 栖鉴根据录制日期匹配佩戴人。归档时手动填写的员工优先。历史记录没有录制时间时进入日期待核实统计。看到“佩戴者待确认”时核查绑定日期，或到「录音档案 → 管理」登记正确员工。
3. 打开「更多 → 服务标准 → 新增话术」。用“迎宾问候”示例练习：场景选“餐厅服务”，触发条件填“客人进店首次接待时”，标准说法填“您好，欢迎光临”，允许表达填门店同意使用的替代说法。确认后勾选「启用此话术」，选择生效日期，保存话术版本。
4. 以后通过「编辑话术」保存新版本。在新版本取消启用即可停用。对昨日录音补检查时，应填写该标准在门店实际开始执行的日期。相同生效日以最后保存的版本为准。
5. 手工上传练习素材时勾选「测试录音」。正式日报排除已标记测试的记录、旧版测试标记和内置演示。用实际业务前应抽查录制时间、设备绑定和转写质量。

## 4. 预览，核对并启用

1. 回到「企微连接」，默认显示昨日，也可选更早的录制日期。先看正式录音总数、已分析、待分析和失败数。没有录音或分析尚未完成时，日报会写出覆盖情况。
2. 老录音已有转写时点「用已有转写检查话术」。系统使用对应日期生效的规则和转写原文调用 DeepSeek 进行语义核对。当日自动推送也会尝试补检查。若分析失败，到录音详情核查分析状态，确认 DeepSeek 配置后重试。
3. 展开「话术依据与人工复核」，选择发言并回听，确认真实说话人后保存复核结论。未确认的发言以“说话人待确认”列出；重叠发言不能确认为个人偏差。多人录音可在「原话转写」将说话人分组人工命名为具体员工姓名或“顾客”。没有证据时显示“证据不足”。事件和待办的纠正、排除、办结仍在原录音详情操作。
4. 点「预览群消息」查看经脱敏的实际文本格式。本机预览可定位证据；群内仅收到摘要。遇到无法可靠脱敏的字段，群消息指引管理人员回到本机查看。
5. 勾选「每日自动发送」，确认“北京时间 09:00”，点击「保存推送设置」。关闭网页后，后台继续运行。主机休眠或停机时无法投递；当天重新启动后会补发昨日未创建的日报。更早日期可手动选择补发。
6. 需要立即发送时点「发送该日日报」。长日报分条编号。「发送记录」显示已送达条数，可展开当次群消息。已发送日报保留原快照；补传录音、人工纠正后，可预览并点「发送更新版」。

## 5. 常见情况

| 看到的情况 | 门店可以怎么做 |
|---|---|
| 地址已保存，但群里没有测试消息 | 核对是否点了测试、是否为创建推送的群。若显示错误码，检查机器人是否仍在群内、地址是否完整、主机能否访问企微。 |
| 有录音却没有员工话术结果 | 核对录制日期、启用标准及场景。检查转写是否完成，点「用已有转写检查话术」。说话人或触发条件不清时回听核实。 |
| 只有部分消息收到 | 查看“已送达 n/N”。明确限流、连接超时会有限次重试，成功分条会被跳过。持续失败时修复原因后点「重试」。 |
| 显示“回执未知” | 到目标群核对第 n+1 条。收到就选「已收到」，系统继续下一条；确认群内没有该条才选「确认未收到」。 |
| 没有权限 | 管理员维护群地址、定时、员工绑定、话术和发送。经理可预览、回听与复核。 |
| 09:00 后才收到录音 | 在预览中选择原录制日期，检查话术、更新待办后点「发送更新版」。 |
| 电脑重启后没有日报 | 双击应用目录的「启动栖鉴.cmd」。检查已开启自动发送、主机联网且未休眠，并在“发送记录”核对状态。 |

上线核验由管理群成员确认测试消息和首份实际定时日报，再抽查一条事件、员工话术和待办与相应录音是否一致。
