# 栖鉴 · 酒店智能巡检与服务分析
同一家门店通过摄像头巡检公区，通过胸牌录音复盘员工服务，通过前台通话确认客需并跟进工单。

应用目录为 `hotel-intellegence/`。Windows 安装依赖、构建网页、准备模型后，双击应用内的“启动栖鉴.cmd”访问本机工作台。已有运行数据位于 `%LOCALAPPDATA%\HotelVoice`。
